2. 처리하는 정보

2-1. 운영자가 직접 수집하는 정보 — 없음

운영자는 이 앱을 위한 서버를 운영하지 않습니다. 회원가입·로그인이 없고, 이름·연락처·위치·사진 등 개인정보를 운영자에게 전송하지 않습니다. 앱은 위치·연락처·카메라·마이크·저장소 접근 권한을 요청하지 않습니다.

2-2. 기기 안에만 저장되는 정보

다음 정보는 이용자의 기기(앱 내부 저장 공간)에만 저장되며 운영자에게 전송되지 않습니다.

  • 게임 진행 기록(세이브 슬롯, 자동 저장)
  • 게임 설정
  • 「길손의 보시」 광고 보상의 하루 이용 횟수
  • 웹 내용물 업데이트 관련 기록(확인한 주소, 적용에 실패한 버전)

기기의 Android 백업 기능이 켜져 있으면, Android 시스템이 앱 데이터를 이용자 본인의 Google 계정 백업에 포함할 수 있습니다. 이 백업은 Google이 이용자 계정에 대해 처리하며 운영자는 그 내용에 접근할 수 없습니다.

2-3. 광고 제공 과정에서 처리되는 정보 (Google AdMob)

앱은 이용자가 원할 때만 보는 보상형 광고(「길손의 보시」)를 위해 Google의 Google Mobile Ads SDK(AdMob)를 사용합니다. 이 SDK는 광고를 요청하거나 표시할 때 Google의 공개 문서에 따라 다음 정보를 자동으로 수집하여 Google에 전송합니다.

  • IP 주소(기기의 대략적인 위치를 추정하는 데 쓰일 수 있음)
  • 앱 이용 기록(앱 실행, 탭, 동영상 시청 등 광고와 관련된 상호작용)
  • 진단 정보(앱과 SDK의 성능 정보, 앱 실행 시간, 오류 등)
  • 기기·계정 식별자(Android 광고 ID, 앱 세트 ID 등)

Google은 이 정보를 광고 제공, 분석, 부정 행위 방지 목적으로 사용합니다. 자세한 내용은 Google의 문서를 참고하세요: Google Mobile Ads SDK 데이터 공개.

2-4. 게임 내용물 업데이트 과정에서 처리되는 정보 (GitHub)

앱은 실행할 때 새 게임 내용물이 있는지 확인하고, 있으면 내려받습니다. 이 파일은 GitHub, Inc.가 운영하는 GitHub Releases(github.com/reddol18/gyj_release)에서 받습니다. 이때 일반적인 인터넷 통신과 마찬가지로 GitHub이 IP 주소, 요청 시각, 요청한 파일, 요청 헤더(앱 식별자·업데이트 모듈 버전·Android 버전이 담긴 User-Agent)를 접속 기록으로 처리할 수 있습니다. 운영자는 이 접속 기록을 받거나 열람하지 않습니다. 업데이트 모듈의 통계 전송 기능은 꺼 두었으므로, 업데이트 모듈 제작사(Capgo)의 서버로는 어떤 정보도 보내지 않습니다.

2-5. 세이브 파일 내보내기

게임 안의 「세이브 파일 내보내기」는 이용자가 직접 기기의 공유 화면이나 다운로드로 파일을 꺼내는 기능입니다. 파일에는 게임 진행 기록, 설정, 앱 버전, 기기 환경 정보(브라우저 식별 문자열, 화면 크기)가 담깁니다. 앱은 이 파일을 어디로도 자동으로 보내지 않으며, 이용자가 고른 곳(예: 메일, 메신저)으로만 전달됩니다.

6. 이용자의 권리와 선택권

  • 광고는 선택 사항입니다. 「길손의 보시」 광고는 이용자가 직접 눌렀을 때만 나오며, 보지 않아도 게임을 끝까지 진행할 수 있습니다.
  • 광고 ID 재설정·삭제: Android 기기의 설정(예: 설정 → 개인정보 보호 → 광고, 또는 설정 → Google → 광고)에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 메뉴 이름은 기기와 Android 버전에 따라 다를 수 있습니다.
  • 맞춤 광고 거부: 같은 기기 설정에서 광고 개인 최적화를 끄거나, Google 내 광고 센터에서 맞춤 광고를 관리할 수 있습니다.
  • 유럽경제지역(EEA)·영국·스위스 이용자: 광고를 처음 요청할 때 Google의 동의 관리 도구(UMP)를 통해 동의 여부를 묻습니다. 동의하지 않으면 광고가 표시되지 않을 수 있으며, 게임 진행에는 영향이 없습니다.
  • 기기 안의 데이터 삭제: 앱을 삭제하거나 기기 설정에서 앱 데이터를 지우면 기기 안의 게임 데이터가 모두 지워집니다.
  • Google·GitHub이 처리하는 정보: 운영자는 이 정보를 보유하지 않으므로, 열람·정정·삭제 요청은 각 회사의 개인정보처리방침에 안내된 방법으로 하실 수 있습니다. 운영자에게 문의하시면 가능한 범위에서 안내해 드립니다.

2. Information We Process

2-1. Information collected by the Developer — none

The Developer does not operate any server for the App. There is no account or sign-in, and the App does not send your name, contact details, location, photos or other personal information to the Developer. The App does not request location, contacts, camera, microphone or storage permissions.

2-2. Information stored only on your device

The following is stored only in the App's private storage on your device and is never sent to the Developer:

  • Game progress (save slots, autosave)
  • Game settings
  • The daily count of "길손의 보시" (traveler's alms) ad rewards
  • Update-related records (the checked address, versions that failed to apply)

If Android backup is enabled on your device, the Android system may include the App's data in your own Google account backup. That backup is handled by Google for your account; the Developer cannot access it.

2-3. Information processed for ads (Google AdMob)

The App uses Google's Google Mobile Ads SDK (AdMob) to show an optional rewarded ad ("길손의 보시") that you choose to watch. According to Google's public documentation, when an ad is requested or shown the SDK automatically collects and sends the following to Google:

  • IP address (which may be used to estimate the general location of the device)
  • Product interactions (app launch, taps, video views)
  • Diagnostic information (app and SDK performance, app launch time, errors)
  • Device and account identifiers (Android advertising ID, app set ID, and similar)

Google uses this information for advertising, analytics and fraud prevention. See Google's Google Mobile Ads SDK data disclosure.

2-4. Information processed for content updates (GitHub)

When the App starts, it checks for new game content and downloads it if available. These files are served from GitHub Releases (github.com/reddol18/gyj_release), operated by GitHub, Inc. As with any internet request, GitHub may process your IP address, the request time, the requested file and request headers (a User-Agent containing the app ID, the update module version and the Android version) as access logs. The Developer does not receive or view these logs. Statistics reporting of the update module is turned off, so nothing is sent to the update module vendor (Capgo).

2-5. Exporting save files

The in-game "export save file" feature lets you take a file out yourself through your device's share sheet or download. The file contains game progress, settings, the app version and device environment details (browser identification string, screen size). The App does not send this file anywhere automatically; it goes only where you choose (for example, email or a messenger).

6. Your Rights and Choices

  • Ads are optional. The "길손의 보시" ad appears only when you tap it, and you can finish the game without watching any ads.
  • Reset or delete your advertising ID in your Android device settings (for example, Settings → Privacy → Ads, or Settings → Google → Ads). Menu names vary by device and Android version.
  • Opt out of personalized ads in the same device settings, or manage them at Google My Ad Center.
  • Users in the EEA, the UK and Switzerland are asked for consent through Google's consent tool (UMP) when an ad is first requested. If you do not consent, ads may not be shown; game progress is not affected.
  • Deleting on-device data: uninstalling the App or clearing its data in device settings deletes all game data on the device.
  • Information processed by Google or GitHub: the Developer does not hold it. You can request access, correction or deletion through the methods in each company's privacy policy. Contact the Developer and we will help as far as we can.

7. Children

The App is not directed to children under 13, and the Developer does not knowingly collect personal information from children under 13.

8. Security

  • The Developer does not store user information on any server.
  • Communication by the ad SDK and update downloads is encrypted with HTTPS (TLS).
  • Downloaded update files are verified with a SHA-256 checksum before they are applied.
  • The App does not request device permissions that the game does not need.
